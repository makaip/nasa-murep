## 8. Methods claims checked against the code

- Ocean colour: AQUA MODIS **L2 OC swath** files (E:\satdata\cdom\...\AQUA_MODIS.<date>T<time>.L2.OC.nc), variables read from `geophysical_data`, binned to the 250 x 250 grid as a **daily** mean of all swath pixels (data/preprocessing/pickler_processors.py:197-265, pickler_utils.py:61-77). Not L3 monthly/weekly composites. Weekly/monthly values in the analysis are means of these daily grids.
- Quality flags: **no code applies l2_flags** (no reference to l2_flags/flags anywhere in data/ or experiments/). Cloud/land/glint removal is only what the L2 files already contain as fill values (decoded to NaN by xarray), plus range limits: Chl 0-100 mg m^-3 (pickler_config.py:48-49), a_CDOM(412) <= 1 m^-1 clip.
- SST: **MUR L4** (MUR-JPL-L4-GLOB-v4.1, `analysed_sst`; pickler_config.py:16, 29) in all violins, maps, IF/sigma classification and K-means. No MODIS SST is used.
- Figure 6 and the 2018 -1 sigma maps (Fig. 7) in the draft were made in nasa-murep-local (w_hist notebooks) with the week-of-year climatology rule, which classifies 13.2% of pixels (13.21% on v4 data); the redo monthly rule gives 12.87%.
